## About

BLACKLISTED.MN is a platform for fair rental market in Mongolia. It allows tenants to review landlords and vice versa, creating transparency in the rental market.

## Features

- Dark theme with neon accents
- Lady Justice scroll animation
- Search functionality for landlords and tenants
- Testimonials and reviews
- Contact form
- Mongolian and English support

## Quick Start (Standalone)

Open \standalone/index.html\ in your browser to see the design.
